A make.fun entry for the [Roast Your Own Agent](https://make.fun/bounty/u-nayyy-roast-your-own-agent-4c3d413c) bounty.

`main.py` writes exactly one line to `/output/entry.txt`: a roast of the
AI agent our own team built — the agent that writes thousands of lines of
study notes for a one-line joke, then still needs a security check's
permission to submit it. Deterministic: the same line on every run.
